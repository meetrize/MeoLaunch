# 03 — 功能规格

## 1. 应用列表与过滤

### 1.1 扫描范围

| 路径 | 默认 |
|------|------|
| `/Applications` | 开启 |
| `/System/Applications` | 开启 |
| `~/Applications` | 开启 |
| 自定义路径列表 | 配置可加 |

规则：

- 只收录顶层（或递归一层）以 `.app` 结尾的包
- 跳过 `Contents` 内部嵌套、明显 helper（可配置）
- 隐藏应用：`LSUIElement` 或名称以 `.` 开头的默认跳过（可配置「显示隐藏应用」）

### 1.2 展示字段

- 图标（异步）
- 显示名：`CFBundleDisplayName` → `CFBundleName` → 文件名去 `.app`

### 1.3 关键字过滤

- 搜索框位于 Overlay 顶部居中（或顶部偏上）
- 实时过滤，无防抖或 16–33ms 轻防抖
- 匹配规则（MVP）：不区分大小写的子串
- 无结果：居中提示「无匹配应用」
- 打开 Overlay 时：
  - 可配置自动 focus 搜索框（默认开）
  - Esc：若搜索非空则清空；若已空则关闭 Overlay

### 1.4 启动应用

- 单击图标启动
- 二期：⌘-Enter 启动选中项；方向键移动选中框

## 2. 网格布局

### 2.1 默认

| 参数 | 默认值 |
|------|--------|
| 列 `cols` | 7 |
| 行 `rows` | 5 |
| 每页容量 | 35 |
| 图标逻辑边长 | 按屏幕高度自适应（约 64–96 pt） |
| 图标下文字 | 单行，居中，必要时省略号 |

### 2.2 自定义

通过配置或简易设置窗修改：

- `cols`：4–10
- `rows`：3–8
- `padding`、`spacing`
- `icon_size`（0 = 自动）
- `show_labels`：bool

修改后立即生效（若 Overlay 打开则重排）。

### 2.3 多屏

MVP：在 **鼠标所在 `NSScreen`** 上铺满 Overlay。  
二期：跟随主屏 / 所有屏镜像。

## 3. 翻页

### 3.1 鼠标滚轮

- Overlay 可见时，接收 `scrollWheel:`
- 垂直滚轮为主；若触控板横向滑动，`deltaX` 也可翻页
- 累积 delta，超过阈值（如 5–10）翻一页，并清零累积，避免一次滑多页（可配置 `page_flip_sensitivity`）
- 边界页：到头后忽略或轻微弹性（MVP：忽略）

### 3.2 其他翻页方式（MVP 可选）

- 触控板两指左右滑
- 底部页指示点点击
- 键盘 ← → / PageUp PageDown

### 3.3 页指示

- Overlay 底部居中小圆点，当前页高亮
- 过滤后若仅一页，可隐藏指示点

## 4. 触发角

### 4.1 默认行为

| 参数 | 默认 |
|------|------|
| 角位 | 左上角 `top_left` |
| 热区边长 | 4 pt（贴屏幕物理角） |
| 触发延迟 | 0 ms（可设 50–100 防误触） |
| 动作 | Toggle Overlay（再进一次可关闭，或仅打开） |

推荐默认：**进入热区 → 打开**；关闭用 Esc / 点空白 / 快捷键，避免角上抖动导致闪烁。

### 4.2 可配置角位

`top_left` | `top_right` | `bottom_left` | `bottom_right` | `off`

### 4.3 与系统触发角冲突

若用户系统偏好里同一角已绑定「调度中心 / 桌面」等：

- 两边可能同时触发
- 安装/设置页用文案提示：关闭系统对应角，或把 meoLaunch 换到其他角

### 4.4 权限

无辅助功能权限时：

- 触发角不可用
- Overlay 仍可通过菜单栏 / 快捷键打开
- 弹出一次性引导

## 5. 唤起与关闭总表

| 输入 | 行为 |
|------|------|
| 触发角 | 打开（默认） |
| 全局快捷键（默认 ⌥Space，可改） | Toggle |
| 菜单栏图标点击 | Toggle |
| Esc | 清搜索或关闭 |
| 点击空白背景 | 关闭 |
| 启动某个 App | 启动后关闭 |
| ⌘W / ⌘Q | 关闭 Overlay / 退出应用（可区分） |

---

## 6. 设置（MVP 最小）

菜单栏 → Preferences：

1. 网格行列
2. 触发角位置与延迟
3. 全局快捷键
4. 扫描路径开关
5. 登录时启动

二期：隐藏特定 App、深色/模糊材质强度。任务栏芯片拖拽排序（区段内重排 + 跨屏搬窗）见 [10-taskbar.md](./10-taskbar.md) §11（已落地）。

---

## 7. 视觉（保持克制）

- 半透明深色遮罩 + 可选 `NSVisualEffectView`（材料：HudWindow / FullScreenUI）
- 图标网格居中
- **不要**做复杂卡片墙、统计条、多区块营销式布局
- 动画：仅 Overlay fade + 可选翻页平移；关闭可关动画以追求极致速度
